# 🔐 SecurePDF Vault

SecurePDF Vault is a MERN-based application for securely uploading, protecting, storing, and sharing PDF documents.

## 🚀 Technology Stack

* ⚛️ React
* 🟢 Node.js
* 🚂 Express
* 🍃 MongoDB
* 📄 PDF processing
* 🔐 JWT authentication
* 🛡️ Security-focused API
* 💳 Subscription payments
* 🪙 Cryptocurrency payment verification

## 📁 Project Structure

```text
securepdf-vault/
├── client/
├── server/
├── uploads/
├── protected-pdfs/
├── .env.example
├── .gitignore
└── README.md
```

## 🔐 Security

The application is designed with security in mind, including:

* Authentication
* Authorization
* Secure document links
* PDF password protection
* File validation
* Rate limiting
* Security headers
* Input validation
* Access logging
* Document expiration
* Secure file storage
